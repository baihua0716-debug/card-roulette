# 卡牌轮盘

卡牌轮盘是一个黑卡 / 白卡概率博弈网页游戏。玩家和电脑轮流从未知牌堆中出牌，通过判断概率、使用技能、管理血量来击败对方。

当前版本：`20260614-save-slots`

在线游玩：<https://baihua0716-debug.github.io/card-roulette/>

## 基本规则

1. 每轮固定生成 8 张牌，牌堆中至少有 1 张黑卡和 1 张白卡。
2. 双方初始血量为 6。任意一方血量归零，对局结束。
3. 黑卡会造成伤害，白卡不会造成伤害。
4. 对电脑出牌后，无论抽到黑卡还是白卡，都会进入电脑回合。
5. 对己方出牌时，如果抽到白卡，可以继续行动；如果抽到黑卡，会对自己造成伤害并结束回合。
6. 如果当前牌堆只剩白卡，可以直接结束本轮并生成新牌序。
7. 当前牌堆抽空后，会生成新一轮牌序，并由玩家先行动。
8. 每次生成新牌序时，双方各获得随机技能，最多持有 8 个。技能不是等概率出现。

## 技能

- 探测：查看当前这一张牌是黑卡还是白卡。
- 洗牌：洗掉当前这一张牌，并公开它是黑卡还是白卡。
- 疗愈：回复 1 点血量，不能超过血量上限。
- 增幅：下一张由使用者打出的牌会消耗此状态；若为黑卡则造成 2 点伤害。不能与超频叠加。
- 冻结：让另一方跳过下一个回合。
- 预示：随机预知一张尚未预知的未来牌，不包括当前这一张。
- 转换：反转当前这一张牌的颜色，但不公开转换前后的结果。
- 夺取：夺取另一方一个技能，并立即使用它。不能连续夺取“夺取”。
- 超频：立刻失去 1 点血量。下一次出牌若为黑卡则造成 3 点伤害；若为白卡，超频状态也会消耗。不能与增幅叠加。
- 涉险：50% 概率回复 2 点血量，50% 概率失去 1 点血量。

技能权重：疗愈、洗牌、增幅、探测更常见；冻结、涉险为基准权重；预示、夺取、转换、超频更少见。

## 电脑难度

- 简单：随机行动为主，辅以基础策略判断。
- 中等：使用默认评分模型，综合当前牌面、血量、技能和风险。
- 困难：使用 2 层搜索、玩家威胁评估、技能保留价值评估、技能连招续算、技能组合学习，并对候选行动进行 200 步 Monte Carlo 模拟。

## 存档

网页右侧有 3 个本机存档栏位：

- 保存：把当前完整对局写入对应栏位。
- 读取：恢复该栏位的完整对局，包括牌堆、回合、血量、技能、日志、当前难度、连胜数、种子状态和困难 AI 的技能组合学习记忆。
- 清除：清空单个栏位。

还可以使用“导出”下载当前对局的 JSON 存档文件，或使用“导入”读取之前导出的 JSON 文件。导入文件有大小限制，用来避免浏览器页面因为异常大文件卡住。

顶部“清存档”会清除本机持久化数据，包括连胜、难度、困难 AI 学习记忆和三个存档栏位。刷新页面后，普通持久化数据和存档栏会保留；浏览器清站点数据后会消失。

## 自定种子

顶部“种子”输入框可以进入自定模式。输入任意文本后点击“应用”，游戏会使用该文本生成可复现的随机序列；在相同种子和相同操作顺序下，牌序、技能和随机结果会保持一致。清空输入框后点击“应用”会恢复随机开局。

## 项目结构

- `index.html`：网页入口。
- `styles.css`：响应式界面样式。
- `game-core.js`：游戏规则、技能效果、状态机、电脑 AI 和存档快照逻辑。
- `game-random.js`：随机数、种子、随机状态快照、加权抽样和洗牌工具。
- `player.js`：玩家 / 电脑角色模型。
- `app.js`：DOM 渲染、玩家交互、localStorage 存档栏、导入导出和持久化绑定。
- `tests/state-machine-regression.mjs`：核心状态机回归测试。
- `streamlit_devil_card_game.py`：原 Streamlit 版本，保留作参考。

## 本地预览

在项目根目录运行任意静态服务器即可，例如：

```powershell
python -m http.server 8000
```

然后访问：

```text
http://127.0.0.1:8000/
```

## 回归测试

```powershell
node tests/state-machine-regression.mjs
```

## GitHub Pages 部署

本项目是纯静态网页，不需要后端服务或构建步骤。将 `main` 分支推送到 GitHub 后，GitHub Pages 会从仓库根目录发布页面。
